# leita, English: the source language. Every other locale translates this
# file's keys. A line is `key = text`; `key.one = text` is one plural form, and
# a bare key is the `other` form. {0} to {9} are arguments, {{ a literal brace.
# The product's name is never written here: it comes in as an argument. A
# message whose {0} is a count is plural.
#
# Terms, kept the same everywhere: scan (reading a disk), Reclaim (the mode
# that finds what can be deleted and made again), Trash (the system's), the
# three charts Sunburst, Treemap and Icicle, licence (British spelling).
